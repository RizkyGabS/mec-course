# M.E.C — More Expression Course

Responsive landing page mockup for More Expression Course in Berastagi, Indonesia.

## Online versions

- [Version 1 — original M.E.C theme](https://rizkygabs.github.io/mec-course/)
- [Version 2 — playful education design](https://rizkygabs.github.io/mec-course/v2.html)

Both pages include a link to switch versions. Version 2 uses AI-generated illustrative student photos; the original M.E.C group photo is supplied by the institution.

## Preview

Open `index.html` (version 1) or `v2.html` (version 2) directly in a browser. Styles, scripts, and reference photos are embedded, so no installation or build is required.

## Content

- Regular Class: Bahasa Inggris (TK–SMA), Matematika (TK–SMA), and Calistung (PAUD–SD).
- Private Class: the same programs plus Semua Pelajaran (SD).
- Established in 2014.
- Location: Jl. Udara Ujung, Tangkulen, Berastagi.
- Facebook: https://www.facebook.com/share/g/19P3Zp51U5/

Testimonials and the WhatsApp number are clearly marked as sample data. The consultation form only prepares a message for copying; it does not send messages or store submissions.

## Hosting

GitHub Pages publishes the root of the `main` branch. The `.nojekyll` file allows the static HTML to be served directly.

Replace the dummy WhatsApp number and sample testimonials before using this mockup as the institution's production website.
